# Contributing

Thanks for considering contributing to WikiMolGen!

## Issues

- Check existing issues before opening a new one
- Include steps to reproduce for bugs
- For feature requests, describe the use case

## Pull Requests

1. Fork the repository
2. Create a feature branch from `master`
3. Make your changes
4. Submit a PR with a clear description of what you changed and why

## Code style

- Follow the existing code conventions
- Keep changes focused - one PR per feature/fix
